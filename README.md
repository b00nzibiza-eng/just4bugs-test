## Deutsch

Winzige Spielzeugfiguren gegen Krabbelviecher auf dem Frühstückstisch. Koop für 1 bis 4 Spieler.
Frühe Testversion – Feedback ist willkommen!

**Sprache:** Das Spiel startet in der Sprache deines Geräts. Umstellen: Einstellungen → „SPRACHE: …“ (Deutsch, Englisch, Spanisch).

**Updates kommen meist von allein:** Das Spiel lädt kleine Update-Pakete beim Start selbst herunter.
Dann steht im Hauptmenü „UPDATE … NEU STARTEN“ (PC) bzw. „APP SCHLIESSEN“ (Handy) – antippen
bzw. die App einmal schließen und wieder öffnen, schon läuft die neue Version.
Nur selten (größere Umbauten) zeigt das Spiel „UPDATE … LADEN“ – dann einmal die neue APK/ZIP laden.
Die aktuelle Version steht unten rechts im Hauptmenü. **Ab Version 0.10** funktionieren die automatischen Updates.

### Android installieren

1. APK über den Link oben herunterladen und antippen.
2. Android fragt, ob der Browser Apps installieren darf: **Einstellungen → „Aus dieser Quelle zulassen“ → zurück → Installieren**.
3. Falls Google Play Protect warnt: **„Weitere Details“ → „Trotzdem installieren“** (die App ist nur nicht aus dem Play Store).
4. Updates einfach über die alte Version installieren – nichts deinstallieren.

Steuerung: linker Stick laufen; rechter Stick leicht = zielen, weit (Knopf wird rot) = schießen; rote Taste = Spezial. Handy quer halten.

### Windows

ZIP entpacken, `Just4Bugs.exe` starten. Bei „Der Computer wurde durch Windows geschützt“: **Weitere Informationen → Trotzdem ausführen**.
Steuerung: WASD laufen, Maus zielen + Linksklick schießen, Leertaste/Rechtsklick Spezial, Esc Pause.

### Zusammen spielen

- **Gleiches WLAN:** Einer klickt „MIT FREUNDEN“ → „SPIEL ERÖFFNEN“, die anderen tippen die Adresse aus der Lobby ein und drücken „BEITRETEN“.
- **Übers Internet:** Alle installieren das kostenlose **Radmin VPN**, treten demselben Netzwerk bei, und die anderen tippen die Radmin-Adresse des Gastgebers (beginnt mit 26.) ein.
- Handy und PC können zusammen spielen. Alle brauchen dieselbe Version.

## English

Tiny toy figures versus creepy-crawlies on the breakfast table. Co-op for 1 to 4 players.
Early test version – feedback is very welcome!

**Language:** The game starts in your device's language. To switch: Settings → "LANGUAGE: …" (German, English, Spanish).

**Updates usually arrive on their own:** the game downloads small update packs when it starts.
The main menu then shows "UPDATE …: RESTART" (PC) or "UPDATE …: CLOSE APP" (phone) – tap it,
or close the app once and reopen it, and the new version is running.
Only after bigger changes does it say "DOWNLOAD UPDATE …" – then download the APK/ZIP once more.
Your version is shown at the bottom right of the main menu. Automatic updates work **from version 0.10 on**.

### Installing on Android

1. Download the APK with the link above and tap it.
2. Android asks whether your browser may install apps: **Settings → "Allow from this source" → back → Install**.
3. If Google Play Protect warns you: **"More details" → "Install anyway"** (the app just isn't from the Play Store).
4. Install updates over the old version – no need to uninstall.

Controls: left stick moves; right stick pushed lightly = aim, pushed far (knob turns red) = shoot; red button = special. Hold the phone sideways.

### Windows

Unzip, start `Just4Bugs.exe`. If you see "Windows protected your PC": **More info → Run anyway**.
Controls: WASD move, mouse aims + left click shoots, Space/right click special, Esc pause.

### Playing together

- **Same Wi-Fi:** one player clicks "WITH FRIENDS" → "HOST GAME", the others type in the address shown in the lobby and press "JOIN".
- **Over the internet:** everyone installs the free **Radmin VPN** and joins the same network; the others type in the host's Radmin address (starts with 26.).
- Phones and PCs can play together. Everyone needs the same version.

## Español

Figuras de juguete diminutas contra bichos en la mesa del desayuno. Cooperativo para 1 a 4 jugadores.
Versión de prueba temprana: ¡se agradecen los comentarios!

**Idioma:** el juego arranca en el idioma de tu dispositivo. Para cambiarlo: Ajustes → «IDIOMA: …» (alemán, inglés, español).

**Las actualizaciones suelen llegar solas:** al arrancar, el juego descarga pequeños paquetes de actualización.
En el menú principal aparece «ACTUALIZACIÓN …: REINICIAR» (PC) o «ACTUALIZACIÓN …: CERRAR APP» (móvil):
tócalo o cierra la app y vuelve a abrirla, y ya tienes la nueva versión.
Solo tras cambios grandes aparece «DESCARGAR ACTUALIZACIÓN …»: entonces descarga otra vez el APK/ZIP.
Tu versión aparece abajo a la derecha en el menú principal. Las actualizaciones automáticas funcionan **a partir de la versión 0.10**.

### Instalar en Android

1. Descarga el APK con el enlace de arriba y tócalo.
2. Android pregunta si el navegador puede instalar apps: **Ajustes → «Permitir de esta fuente» → atrás → Instalar**.
3. Si Google Play Protect avisa: **«Más detalles» → «Instalar de todas formas»** (la app simplemente no es de la Play Store).
4. Instala las actualizaciones encima de la versión anterior, sin desinstalar.

Controles: stick izquierdo para moverse; stick derecho un poco = apuntar, a fondo (el botón se pone rojo) = disparar; botón rojo = especial. Sujeta el móvil en horizontal.

### Windows

Descomprime el ZIP y abre `Just4Bugs.exe`. Si aparece «Windows protegió su PC»: **Más información → Ejecutar de todas formas**.
Controles: WASD moverse, ratón apuntar + clic izquierdo disparar, Espacio/clic derecho especial, Esc pausa.

### Jugar juntos

- **Misma Wi-Fi:** un jugador pulsa «CON AMIGOS» → «CREAR PARTIDA»; los demás escriben la dirección que aparece en la sala y pulsan «UNIRSE».
- **Por internet:** todos instaláis el programa gratuito **Radmin VPN** y os unís a la misma red; los demás escriben la dirección Radmin del anfitrión (empieza por 26.).
- Móviles y PC pueden jugar juntos. Todos necesitáis la misma versión.
