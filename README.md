# Just 4 Bugs – Testversion

Winzige Spielzeugfiguren gegen Krabbelviecher auf dem Frühstückstisch. Koop für 1 bis 4 Spieler.
Frühe Testversion – Feedback ist willkommen!

## Download (immer die neueste Version)

- **Android:** [Just4Bugs_Android.apk](https://github.com/b00nzibiza-eng/just4bugs-test/releases/latest/download/Just4Bugs_Android.apk)
- **Windows:** [Just4Bugs_Windows.zip](https://github.com/b00nzibiza-eng/just4bugs-test/releases/latest/download/Just4Bugs_Windows.zip)

**Updates kommen meist von allein:** Das Spiel lädt kleine Update-Pakete beim Start selbst herunter.
Dann steht im Hauptmenü „UPDATE … NEU STARTEN“ (PC) bzw. „APP SCHLIESSEN“ (Handy) – einfach antippen
bzw. die App einmal schließen und wieder öffnen, schon läuft die neue Version.
Nur selten (größere Umbauten) zeigt das Spiel „UPDATE … LADEN“ – dann einmal die neue APK/ZIP laden.
Die aktuelle Version steht unten rechts im Hauptmenü. **Ab Version 0.10** funktionieren die automatischen Updates.

## Android installieren

1. APK über den Link oben herunterladen und antippen.
2. Android fragt, ob der Browser Apps installieren darf: **Einstellungen → „Aus dieser Quelle zulassen“ → zurück → Installieren**.
3. Falls Google Play Protect warnt: **„Weitere Details“ → „Trotzdem installieren“** (die App ist nur nicht aus dem Play Store).
4. Updates einfach über die alte Version installieren – nichts deinstallieren.

Steuerung: linker Stick laufen; rechter Stick leicht = zielen, weit (Knopf wird rot) = schießen; rote Taste = Spezial. Handy quer halten.

## Windows

ZIP entpacken, `Just4Bugs.exe` starten. Bei „Der Computer wurde durch Windows geschützt“: **Weitere Informationen → Trotzdem ausführen**.

## Zusammen spielen

- **Gleiches WLAN:** Einer klickt „Mit Freunden“ und eröffnet, die anderen tippen die Adresse aus der Lobby ein.
- **Übers Internet:** Alle installieren das kostenlose **Radmin VPN**, treten demselben Netzwerk bei, und die anderen tippen die Radmin-Adresse des Gastgebers (beginnt mit 26.) ein.
- Handy und PC können zusammen spielen. Alle brauchen dieselbe Version.
